## OptionalApps

These apps can be installed after setup, and they are also available on GitHub and the MosaicStore. If the user changes their mind, they can uninstall them at any time. Currently included:
- [Heliboard](https://github.com/HeliBorg/HeliBoard) by HeliBorg
- [Etar](https://github.com/Etar-Group/Etar-Calendar) by Etar-Group/LineageOS
